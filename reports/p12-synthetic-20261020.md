# P12：合成文献问答模型复测

日期：2026-10-20

## 数据与冻结

- 只使用仓库内两份合成 PDF；没有访问、上传或引用毕设文献。
- 冻结集 6 题：4 道可回答题、2 道应拒答题，含 1 道跨论文比较。
- 5 条 gold 引文经原 PDF 页码和文本校验。清单哈希见 [`p12-synthetic-manifest.json`](../evals/p12-synthetic-manifest.json)；题集在模型运行前由 `2a6b1cc` 冻结。
- 样本很小且均为英文合成文档。一次运行不能代表真实文献泛化。

## 结果

使用 DeepSeek `deepseek-flash`，即官方当前列出的 DeepSeek-V4.1-Flash-1017；接口采用非思考 JSON 模式。[官方 API 参数](https://api-docs.deepseek.com/api/create-chat-completion/)、[官方模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)

| 指标 | BM25 摘录模式 | BM25 + 模型筛选、生成、审查 |
|---|---:|---:|
| 可回答题覆盖 | 4/4 | 4/4 |
| 可回答题命中 gold 页 | 4/4 | 4/4 |
| 应拒答题未输出内容 | 1/2 | 2/2 |
| 应拒答题出现摘录或 claim | 1/2 | 0/2 |
| gold 页引文精度 | 6/7（85.7%） | 9/9（100%） |
| claim 支持审查通过 | 8/8 | 9/9 |
| 完整回答 | 不适用 | 4/4 |

摘录模式只展示经原文核验的摘录，页面明确说明它不会自动综合。`1/2` 表示有一道拒答题仍显示了相关但不足以回答“哪个区域最慢”的摘录；这不是模型生成了错误结论。模型审查路径对此题正确拒答。这个小样本暴露了两种模式的输出边界。

模型实测共 17 次 API 请求，输入 5,951 tokens，输出 1,035 tokens，费用峰时保守上界 `$0.0030273`。费用按全输入缓存未命中峰时价 `$0.30/M`、输出 `$1.20/M` 计算，缓存命中会更低；这不是供应商账单。官方价格与高峰时段规则见[价格页](https://api-docs.deepseek.com/quick_start/pricing/)。本轮已并入本地忽略的费用账本，项目累计上界 `$0.2579835`，低于 `$0.50` 项目上限。

## 复现

```powershell
$env:PYTHONPATH = '.local/p6-runtime;.local/p9-web-runtime'
python -m scripts.build_p12_synthetic
python -m papertrail.gold --sources .local/p12-synthetic/sources.yaml --gold evals/p12-synthetic-gold.jsonl --minimum-questions 6
python -m papertrail.evaluate_qa --db .local/p12-synthetic/papertrail.sqlite3 --gold evals/p12-synthetic-gold.jsonl --out reports/p12-synthetic-20261020.json --mode bm25 --limit 5 --minimum-questions 6
```

真实模型复现还需按 `.env.example` 提供 DeepSeek 环境变量。评测器在调用前用本地预算文件和每请求保守上界阻断超额请求。不要把私人论文路径替换进这套 DeepSeek 测试。

## 结论边界

结果支持：在这两份固定合成 PDF 的 6 个问题上，模型审查路径 4/4 回答可答题、9/9 claims 通过审查、2/2 拒答题正确拒答。不能据此声称生产可靠性、真实语料质量或普遍 100% 准确率。P11 私人语料上的页面召回不足问题仍未解决；需要在本地或合成的多主题、同义表达、冲突版本及扫描 PDF 数据上扩大盲测。
