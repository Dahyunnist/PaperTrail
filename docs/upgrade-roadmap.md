# PaperTrail RAG 升级路线

## P0：可信基线（已完成）

统一只评原论文证据，修复阅读笔记污染；冻结 34 道问题和 37 条证据，按题型/错因记录 Recall、MRR、nDCG、延迟和拒答。

## P1：检索质量（语义检索已完成；交叉编码器因本机权重不完整未启用）

复用本机 BGE 中文模型，建立可增量重建的页/段向量；比较 BM25、dense、hybrid、cross-encoder 重排。只在黄金集实测增益后调整默认模式。

## P2：证据综合与记忆（本机生成接口已实现；实模型验证依赖本机 Ollama 与模型权重）

加入本地 LLM 综合回答。每项 claim 分别检查原文存在性和支持关系；OCR、笔记、过期版本隔离。会话短记忆与个人长期记忆分离，纳入上下文预算和跨轮测试。

## P3：可靠运行（索引队列与恢复已完成）

索引任务持久化、异步执行、断点恢复、重试和进度可查；个人上传权限及删除边界有审计记录。

## P4：Agent 接口（已完成）

按 MCP 标准暴露只读检索/证据 tools 和资源；用真实 MCP 客户端联调 schema、调用、错误、资源列表与读取。

## P5：评测与交付（轨迹、人工 reward 与导出已完成；未训练策略模型）

保留基线、消融、失败样本和端到端轨迹；量化用户任务完成率、成本及延迟。定义可执行 Agentic-RL reward 与轨迹数据；样本不足时不训练、不声称训练。

每阶段都改代码、跑针对性与全量验证、写中文学习记录，并单独以中文 message 提交。原 PDF 只读；`.local/`、密钥和本机路径不进 Git。

## P6：真实生成模型验收（已完成实跑，质量未达标）

冻结 34 题及 37 条证据指针；用 DeepSeek OpenAI-compatible API 对照抽取式和生成式问答。逐请求成本硬停 `$0.19`；只发送问题及已验证公开论文短摘录。记录真实 token、费用、延迟、引用和人工抽查，不以 mock 代替实跑。

## P7：页召回与重排消融（已完成；LLM reranker 保持可选）

从失败题定位召回错页；对照 100-chunk 候选、12 页候选池和 LLM 重排前后 Recall/MRR/nDCG。目标页仍有 11/31 道题不在候选池，故不更改默认模式。

## P8：答题覆盖与端到端复验（开发集回归完成；质量仍未达标）

补候选证据相关性筛选、一次定向补检、claim relevance/coverage 审查和逐题费用记录。明确 P6 题集仅为开发集。在同一 P7 重排检索上完成人工抽查：5 正确、2 部分正确、0 错误、24/31 可答题错误拒答、3/3 不可答题正确拒答。跨论文、冲突、多跳仍全拒答；12 篇 pilot 语料与独立新题集不足以证明生产质量。


## P9：扩展语料与独立评测（完成，质量未达标）

覆盖 62 个唯一原始 PDF；82 个位置全部成功解析。冻结 30 道非盲新题。BM25/混合 Recall@10 均为 0.778，BGE 密集重排为 0.481。真实模型只回答 5/27 可回答题；人工核查 4 正确、1 部分、0 错误，22 次错误拒答；跨论文、冲突、多跳题均未答。全部测试通过，但不宣称生产级。详见 `docs/learning/stage-P9.md`。

## P10：复杂问题覆盖与最终交付（完成，质量仍未达标）

Web 增加可配置检索模式/证据数，保留 BM25 默认。本机扩展语料与 `hybrid_bge_wide` 页面已通过 HTTP 及浏览器验证。问答增加最多 4 个子问题的分别检索、部分回答覆盖标记、空 claims 单次短重试；生成预算为 800 tokens，引用和逐 claim 支持标准不变。全仓测试 32 passed。
