# P14 困难问题诊断

## 评测设计

P14 增加 12 道新编问题，覆盖多步数值推导、跨文献证据聚合、统计结论边界和证据不足拒答。题集包含 9 道可答题、3 道应拒答题；19 条 gold 引文均通过 PDF 页码与 SHA-256 校验，和已有黄金集没有完全相同的问题。

本次复用 P13 的 4 份一页合成 PDF，属于新问题诊断，不是独立文献集盲测。题目与逐题结果见 [P14 gold](../../evals/p14-challenge-gold-20261023.jsonl)、[冻结清单](../../evals/p14-challenge-manifest-20261023.json) 和 [模型报告](../../reports/p14-challenge-20261023.json)。

## 真实模型结果

使用 DeepSeek `deepseek-flash`，BM25 检索，最多组织 8 条证据。单次评测 64 次 API 请求，费用上界 `$0.0151794`，生成回答的中位耗时约 4.44 秒。评测使用本地合成资料，不含个人毕设文献。

| 指标 | 结果 |
|---|---:|
| 可答题有回答 | 8/9（88.9%） |
| 自动判为完整覆盖 | 7/9（77.8%） |
| gold 页引用精度 | 100% |
| 覆盖全部 gold 页的可答题 | 7/9（77.8%） |
| gold 页覆盖 | 80.0% |
| 正确拒答 / 误答 | 3/3 / 0 |
| claim 支持审查通过 | 22/26（84.6%） |

## 人工复核

逐题检查发现，自动覆盖指标不等于事实正确率。P14-01 对可计算的货运失败数量拒答；P14-03 未给出题目要求的相对降幅；P14-04 混淆了两篇研究的样本归属；P14-07 漏掉原文明确给出的总体样本数；P14-11 错称原文没有总体中位数。

这组诊断说明目前的页码级引文校验不能代替 claim 级语义正确性验收。引用都落在正确 PDF 页，并不保证检索到了支持答案的具体句子；自动“完整覆盖”也需要用题目要求的原子事实逐项复核。

## 使用边界

P14 可以作为困难回归集和问题定位依据，不能作为泛化或生产准确率证明。题目数少、语料合成且沿用 P13 文档；模型也有随机性。对外描述应说“在合成挑战集上评测”，不应把自动覆盖率写成答案正确率。
