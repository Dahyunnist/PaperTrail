# P9：全量语料与独立评测

## 语料

本阶段使用用户已盘点并授权的 `E:\毕设` 六个文献目录。索引清单 `configs/s1-expanded.jsonl` 含 82 个原始 PDF 位置，对应 62 个唯一 PDF 哈希。相对 12 篇 pilot，新增 50 篇唯一原始论文。20 个重复位置合并到同哈希版本；同名但哈希不同的版本继续分开保存。

索引处理 82 个位置，零低文本、零解析失败。新增处理共 23,863 个文本块；扩展库原始 PDF 共 36,720 个文本块。阅读笔记不进入扩展清单，原 pilot DB 中已有的笔记记录仍留在数据库，但检索限定 `source_type=original_pdf`。

## 题集冻结

P9 是独立于 P6 开发题集的新题集，但不是盲测：题目由同一操作者根据核实后的 PDF 页人工编写，作者也能访问索引和来源。

题集含 30 题：事实定位 10、方法比较 5、跨论文 4、多跳 4、版本冲突 4、不可回答 3。45 条短引文均通过来源 PDF 哈希、页码和原文匹配验证。冻结清单记录题集 SHA-256。Robust Detection 两个不同哈希版本分开引用，未合并其指标。

## 离线检索结果

BM25 的目标页 Recall@10 为 21/27（77.8%），文档 Recall@10 为 27/27（100%），全部证据页命中率为 18/27（66.7%）。BM25 Recall@20 提升到 24/27（88.9%）。这说明主要剩余错误是目标论文内的错页与多证据覆盖不足；扩大候选页数有收益，仍未达到完整证据召回。

本机 BGE 向量产物存在，但当前执行环境缺少 `sentence_transformers`，无法重现 BGE 查询和混合检索对照。没有联网安装依赖，也没有调用模型 API。故不据 BM25 结果更改默认混合检索策略。

## P8 错误拒答归因

P8 的 P6 开发集含 31 道可回答题。模型答出 7 题，错误拒答 24 题。P7 宽候选重排轨迹显示：24 次错误拒答中，19 次重排候选池已有目标页，5 次缺目标页。Claim 支持审查没有拒绝任何已生成 claim。故至少 19 次问题发生在 claim 判定之后，位于回答覆盖/生成门控；5 次属于候选召回不足。现有轨迹未记录生成器拒答理由，不能把前 19 次再精确拆成 coverage gate 与生成器拒答。

## 预算与结论

没有新增模型 API 请求。已用上限仍为 `$0.1613298 / $0.19`。本阶段不运行真实模型 smoke，以免小额余量不足以覆盖请求波动。下一步先补充拒答原因日志，并解决 BGE 离线查询依赖，再复测 P9；真实模型验证需先确认剩余预算可硬停。
