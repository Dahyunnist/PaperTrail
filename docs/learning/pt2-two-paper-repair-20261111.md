# PT-2 两篇显式来源漏检诊断

日期：2026-11-11。固定开发集事后诊断，不是盲测、泛化评测或新基线。原 7/10 分数保持不变。

## 候选与过滤追踪

两题各需两篇来源，共 4 个黄金页。旧 Hybrid 先按全局子块 RRF 融合，再取 50 个子块、去重为 10 个页：

| 题号/黄金页 | BM25 原候选名次 | 向量原候选名次 | RRF 子块名次 | 过滤原因 |
|---|---:|---:|---:|---|
| PT9-03 / p.2 | 59 | 83 | 48 | 进入50候选；重复页占位后唯一页名次36，超K=10 |
| PT9-03 / p.5 | 79 | 9 | 35 | 进入50候选；重复页占位后唯一页名次26，超K=10 |
| PT12-05 / p.7 | 316 | 167 | 未进50 | BM25超200，向量进入；融合后被全局Top-50截断 |
| PT12-05 / p.8 | 45 | 10 | 21 | 进入50候选；重复页占位后唯一页名次19，超K=10 |

因此，4/4 目标页都在 BM25/向量 Top-200 的并集内。损失在跨来源全局融合和唯一页 K=10 过滤；PT12-05 p.7 还被 RRF Top-50 截断。

## 窄修复

新增显式 opt-in 的 `retrieve_explicit_two_paper_pages`。仅当 query 含两个连字符论文别名，且每个别名唯一匹配索引标题时启用：

1. 检索只接收 query 与索引标题；从 query 移除来源别名，减少标题页偏置。
2. BM25、向量各取200条候选，再按 query 明确点名的论文分开融合。
3. 论文内按子块 RRF 排名，每页汇总分数最高的两个不同父段；每篇最多留10页，按论文轮流输出。
4. 不匹配或别名歧义时返回空结果。现有调用方和默认检索不调用此策略。

固定回归只比较两个已见问题。检索过程没有接收黄金页、答案、引用文本或目标哈希；脚本在候选和排序都生成后才读取黄金页做评分。原索引和向量文件先复制到忽略目录中的临时副本；数据库迁移只发生在副本。

## 结果

对照旧冻结轨迹，页面 Recall 分母为4个黄金页，MRR 按每题第一个命中页计算后取两题均值：

| 指标 | 原默认 Hybrid | 显式双论文策略 |
|---|---:|---:|
| Recall@10 | 0/4 = 0.00 | 3/4 = 0.75 |
| 完整题数@10 | 0/2 | 1/2 |
| MRR@10 | 0.0000 | 0.1875 |
| Recall@20 | 1/4 = 0.25 | 4/4 = 1.00 |
| 完整题数@20 | 0/2 | 2/2 |
| MRR@20 | 0.0263 | 0.1875 |

PT12-05 两页在修复输出中排第4和第9；PT9-03 两页排第8和第11。故策略在K=10仍未完整覆盖 PT9-03；两题都需最多20页才完整。旧 RRF Top-50 候选覆盖3/4；BM25/向量 Top-200 并集覆盖4/4；修复后候选并集仍为4/4。结果支持“融合与页预算是主要损失点”，不证明新策略有泛化收益。

独立副本报告：`evals/pt2-two-paper-balance-20261111.json`。报告核验默认 Hybrid 的两题 Top-10 chunk 和 page 顺序与冻结轨迹完全一致；冻结 gold、旧报告、原索引和向量文件哈希均未变化。
