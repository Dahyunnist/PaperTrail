## 恢复与门禁

`scripts/reconcile_pt_usage_ledger.py` 只读原始账本、历史 usage、报告和预登记记录，输出新文件。它仅容忍已知的两字节字面尾缀 `\\n`，记录原件 SHA-256；其余损坏直接失败。输出拒绝覆盖既有文件。

`papertrail/local_llm.py` 在发送托管模型请求前检查 schema v2 的 `model_calls_allowed`。值不是严格布尔 `true` 时拒绝请求。记账函数也执行同一检查。

验证仅使用合成 JSON fixtures 和静态 AST 检查。未打开论文 PDF，未读取来源文档内容，未调用模型。受限环境不允许 pytest 默认临时路径时，测试应把 `--basetemp` 指向仓库 `.tmp`。

## 未决事项

需为 27 条请求找到独立运行报告或账单来源，逐条记录证据后才能重建一次并复核。没有证据时，保持未知和关闭门禁。原账本和只读副本继续保留。
