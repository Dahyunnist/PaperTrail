# P15：单轮问答预算

## 本阶段目标

把一次用户提问中的拆解、证据筛选、答案生成、修复和复核统一放进一个预算，避免单个问题在重试链中无限消耗。

## 实现

- `model_turn_budget()` 用 `ContextVar` 为一次 `ask()` 建立隔离计数，避免并发请求共享计数。
- 所有 `chat_json()` 调用先预留预算，再触达 Ollama 或托管模型。
- 每轮最多 16 次调用；托管模型按最坏输入/输出估价，每轮最多预留 0.05 美元。
- 已预留预算不因请求失败而退回，避免失败重试绕过上限。
- 结果带 `model_budget`，便于检查调用次数与预留额。

## 边界

本地 Ollama 调用有次数上限，没有美元计价。托管模型另受全局账本上限约束。预算按最坏成本预留，可能高于真实账单。

## 验收

测试验证第 17 次模型调用在网络请求前被拒绝；托管调用测试继续验证全局账本与密钥脱敏。
