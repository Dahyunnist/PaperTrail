# PT1：真实论文基准与数据边界

日期：2026-10-23

## 盘点

仓库工作区初始干净；历史 P9、P12、P13、P14 结果与黄金集均保留。真实本地语料盘点记录包含 148 个位置；其中识别出 62 个唯一论文候选 PDF。逐页本地扫描仅在 1 篇论文正文中找到明确的 Creative Commons Attribution 4.0 声明。其余论文没有发现同类声明；这不等于判断它们没有合法使用依据。

可复核子集为 Shumailov 等人的 *AI models collapse when trained on recursively generated data*，DOI `10.1038/s41586-024-07566-y`。PDF 正文标注 CC BY 4.0。评测仍只在本机授权语料上进行；本阶段不把原文、问题、引文、索引或路径送入云端。

## 冻结集

冻结清单和黄金集位于忽略目录：

- `.local/pt1-real-dev-manifest.json`
- `.local/pt1-real-dev-gold.jsonl`

黄金集有 8 道新编开发题，覆盖事实定位和两步证据组合；13 条最小引文集合均通过来源 SHA-256、物理页码和原文验证。清单记录黄金集 SHA-256、来源版本、许可标记与限制。

复现引文校验：

```powershell
python -m papertrail.gold --sources configs/sources.example.yaml --gold .local/pt1-real-dev-gold.jsonl --minimum-questions 1
```

## 限制

当前找到的明确许可证材料只支持 1 篇论文，无法形成目标规模的 30–60 篇语料、40 道以上问题或按论文划分的测试集。本地集只作开发诊断，不发布原文或引文，不报告测试准确率，也不用于模型选择后再称为独立测试。其余用户语料仍可作本地检索诊断，但因本次未核实可再分发许可，未纳入冻结集。

旧 P12 是同一私有语料上的 6 题非盲诊断，历史重复运行结果差异较大，且已暴露页码命中问题。P9、P12、P13、P14 均不重跑、不覆盖、不合并进 PT1。本地历史账本另有重叠；PT2/3 不调用云模型，直到独立核对后仍有可用预算。

## 阶段结论

PT1 交付的是一个本地、开发用途的冻结诊断集和清晰的许可边界，不是有代表性的真实论文基准。PT2 只在该冻结集上比较离线检索，并用新的合成夹具测试解析与跨页行为；结果按小样本诊断解释。
