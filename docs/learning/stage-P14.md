# 阶段 P14：修复多跳问答并校准引用验收

日期：2026-10-20

## 为什么改

P13 冻结基线上 4/22 可答题未完整回答。失败轨迹集中在模型返回无效子问题 ID、短证据句被抽取器丢弃，以及多子问题检索把同一摘录误当作多个问题的证据。旧汇总只检查“是否引用任意一条 gold 页面”，会掩盖跨论文题缺少另一侧证据。

## 实现与数据流

```text
问题拆分
  -> 每个子问题独立筛选候选摘录
  -> 无效结构最多修复重试一次
  -> claim 支持与覆盖审查
  -> 引用原文 / 页面 / 文件哈希校验
  -> 同时统计任意命中、页面覆盖率、全部 gold 页面命中
```

- 缩短短句抽取最小长度，保留有效的简短否定事实。
- 多跳检索逐个子问题筛选，避免跨题复用一条宽泛摘录。
- BM25 回退查询加入 ASCII 前缀匹配，覆盖常见英文复数变化。
- 对无效子问题 ID 和 claim/evidence 结构只修复重试一次，限制费用与循环。
- 在提示与审查中要求百分比计算展示公式。
- 评测新增 `expected_page_coverage` 与 `all_expected_pages_cited`，并保留旧的任意命中字段用于兼容。

## 结果与边界

首次 P13 真实模型运行：18/22 可答题有回答，17/22 完整；跨文献完整回答 0/2，多跳 2/3。修复后在**相同题集**重复运行：22/22 有回答、21/22 完整、4/4 正确拒答；覆盖 23/24 gold 页面，21/22 可答题引用齐全。49 条 claim 中 45 条通过支持审查。费用账本累计峰值上界 `$0.09 / $0.10`。

这属于同题回归诊断，不是独立 holdout。唯一不完整题 P13-21 仍缺少一侧来源，系统以部分回答标记；不能描述为跨文献能力已完全解决。26 题、4 份英语合成 PDF不足以证明真实论文或生产泛化。42 项自动化测试通过。

## 失败路径

1. 模型连续返回无效子问题 ID：最多修复一次，之后该子问题不产生 claim；记录失败，不将无效结构默认为正确。
2. 跨文献问题只找到一侧证据：输出部分状态；页面覆盖指标低于 100%，避免因命中任意一页而记成完整成功。
