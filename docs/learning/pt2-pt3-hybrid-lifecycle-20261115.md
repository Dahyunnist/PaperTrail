## 本轮结果

新增临时合成 PDF 回归：BM25、向量和 hybrid 检索均跟踪版本更新；旧版本 SHA 不再出现在检索结果中；来源删除后，三种模式均不返回旧来源。复用已有生命周期测试，确认变更路径和删除路径的词法索引行为。

定向离线回归覆盖 gold CSV 导入拒绝、确定性评测 manifest、PT-2 固定合成检索、PT-3 引文失败/部分覆盖，以及本轮版本生命周期测试。测试由本地临时 fixture 驱动，不调用模型或网络。

## 边界

本轮只验证既有合成输入和索引生命周期，不创建或改写 gold，不读取私人 PDF。合成测试通过不能证明真实论文检索质量，也不代表 PT-1 人工双标完成；PT-1 仍为 0/40，真实 PT-2/PT-3 验收仍需人工标注、仲裁和来源核验。
