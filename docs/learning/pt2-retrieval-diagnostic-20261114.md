# PT-2 检索与完整证据覆盖离线诊断（2026-11-14）

## 本轮回归

新增两页合成论文的负例：查询只召回第一页时，即使至少命中一页，评测仍判定完整证据页/完整引文集未覆盖；两条必要证据只找到一条，`evidence_item_recall_at_k=0.5`。该用例锁定“页级命中不等于完整证据”的评测口径。

运行现有冻结 PT-2 合成夹具：3 个查询分别以 BM25、字符 TF-IDF + SVD 向量、RRF 检索，共 9 组；9/9 达到该夹具定义的完整证据覆盖。同夹具复跑报告 SHA-256 为 `9602c21652c5413cea79c6e8d980b1692ecd669a652f6099e575f5d52ea09650`，与已提交报告字节一致。定向测试 `tests/test_evaluate.py`、`tests/test_pt2_synthetic_retrieval.py`、`tests/test_pt2_unlabeled_audit.py` 共 **6 项通过**。

所有新增测试资料均由临时 synthetic PDF 夹具生成；冻结夹具仅从仓库既有合成 PDF/查询读取。未读取私人 PDF，未改写 gold，未调用模型。向量模式是字符 TF-IDF + SVD，不是神经 embedding。9 组小型合成结果只证明这些已知场景的回归，不代表真实论文效果或泛化能力。

## PT-1 人工标注最小清单

真实独立 gold 仍为 **0/40**。要解除 PT-2 真实数据验证阻塞，用户需安排两名标注者各自从权威题单领取并独立完成 A/B CSV 的 40 题；逐题核对 DOI 与 PDF SHA，填写最终问题、题型、可答性、答案或拒答理由、最小完整证据集、物理页码、逐字引文/span，并由不同 reviewer 复核。两份 CSV 完成后先运行双人校验与分歧仲裁，再由负责人整理最终 v2 JSONL，通过来源哈希和证据落页校验。具体字段和命令见 [PT-1 双人标注交接清单](pt1-human-handoff-checklist-20261114.md)。
