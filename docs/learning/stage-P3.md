# P3 学习记录：持久异步索引

## 实现

SQLite `index_jobs` 保存排队、运行、完成、带解析问题完成和失败状态。索引工作在线程中执行，页面请求只创建任务。`GET /jobs/<job_id>` 返回状态、尝试次数和逐文件进度。上传 PDF 先写入本机库并记录 SHA-256，再排队索引；完成后更新上传状态。任务失败最多自动尝试三次；进程重启时 running 任务恢复为 queued。

每个任务独立连接 SQLite。索引函数提供可选进度回调，原有同步 CLI 行为不变。上传清单和来源配置仅在任务期间留存，结束后清理；PDF 不原地修改。

## 边界

当前队列适合单机单进程 Web 服务。多个 Web worker 同时抢任务、跨机器锁、取消任务和 OCR 进程隔离尚未实现。单个文件解析错误作为任务结果中的 issues 返回，不会伪装成队列崩溃。

## 验证

```powershell
python -m pytest tests/test_s5_web.py -q
python -m pytest -q
```

两个 Web 测试和全量 12 项测试通过。测试轮询 `/jobs/<job_id>`，并确认完成后可以检索新增文献。

## 经验

长任务状态必须先写入数据库，再开始工作。进度回调与索引事务分开，避免任务状态回写占用文档索引连接。恢复时把遗留 running 任务重新排队，依赖 SHA-256 去重保证重复执行安全。
